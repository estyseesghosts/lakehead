## 0. What `docs/01.md` requires (verbatim-compressed from `zero`)

1. **Repair feed overlays:** Google Feed via AIDLBridge + Neo Feed on existing left-side surface. Diagnose provider discovery vs binding vs lifecycle vs IPC vs gesture vs rendering. No provider special-casing.
2. **Separate move from resize:** move-only drag preserves w/h, free 2D incl. row-to-row, collision/bounds obeyed, no implicit resize. Resize only after tapping resize-arrow. Separate selection / movement / resize-activation / resizing.
3. **Dynamic grid height/scroll:** Normal = content-sized, no scroll when fits in nav-safe area, no empty tail, scroll only on overflow. Edit = always downward-extensible, drag-near-bottom advances viewport, recompute/collapse on exit.
4. **Work-profile naming/sorting:** Display `Work Firefox`, sort by `Firefox`. Prefix after sort key. No hardcoded `Work` in list code. Model prefix separately for future `Shelter`.
5. **Unpin `(×)` placement:** `1×1,1×2,2×1` = top-right; any larger = centered. Stays with tile during move/resize.
6. **Functional shortcuts:** Long-press enters edit+selects tile; tap another tile switches selection+list without re-entering edit; persistent selected-tile concept; real shortcuts listed, functional, empty handled, live updates.
7. **Shortcut pinning (only after 6 works):** Per-row pin control pins to selected tile. Separate app vs available vs tile-pinned. Pinned state per-tile in layout model.
8. **Large-tile icon before pinning:** Tiles > `1×2`/`2×1` with 0 pins: app icon substantially larger, centered, most of tile, no reserved shortcut space.
9. **Pinned-shortcut layout:** Horizontal/square = bottom-edge centered group (not right-aligned). `2×2`=app+1, `2×4`=app+3 → derive general rule. Vertical = app bottom-right + shortcuts upward on right edge. Recompute on resize, no overlap with edit controls, define overflow, app icon distinct.
10. **Order:** 1 feed → 2 move/resize → 3 extent/scroll → 4 sorting → 5 controls → 6 shortcuts → 7 pinning → 8 layouts → 9 tests. Explicit-state design, not more gesture conditions.
